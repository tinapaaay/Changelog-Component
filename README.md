# Changelog Component

A responsive changelog component built with HTML and CSS.

This project displays a list of website updates in a clean timeline layout. I built it to practice CSS positioning, layout, and responsive design.

## Features

- Timeline-style changelog layout
- Responsive design for desktop and mobile
- CSS pseudo-elements for the timeline line and dots
- Semantic HTML using `header`, `section`, `ol`, `li`, and `time`
- Simple and clean card design

## Built With

- HTML5
- CSS3

## What I Practiced

- CSS positioning
- CSS Grid
- Pseudo-elements (`::before`)
- Media queries
- Responsive layouts
- Organizing a small HTML and CSS project
